# 紫微晶集 · Crystal Curation

一个面向晶石爱好者的静态网站原型，使用 HTML5、CSS3 和原生 JavaScript 构建。

## 功能

- 烟雾紫色神秘风格的响应式首页
- 按情绪和需求发现晶石
- 商品分类筛选与关键词搜索
- 收藏、购物袋和提示反馈
- 移动端底部导航
- 内置 SVG 晶石视觉，不依赖外部图片或 CDN
- 可直接用于 GitHub Pages

## 本地运行

直接用浏览器打开 `index.html` 即可。

## GitHub Pages

将 `index.html` 放在仓库根目录，在 GitHub 仓库设置中启用 Pages，并选择默认分支的根目录作为发布源。
